## Evidence and completion

The accepted [numeric](numeric-design.md), [physics](physics-design.md), [navigation](navigation-design.md) and [simulation acceptance](simulation-acceptance.md) documents remain the requirements. This breakdown does not reopen their behavior choices or weaken any target. Approved prototype scenarios become production regression cases; their archive branches are never merged.

Each issue requires real production-code tests, `npm run check` and recorded evidence. Gameplay/UI changes additionally require integrated-browser interaction and visual inspection. Exact replay grows with the implementation instead of being postponed until the end. Human play feedback remains part of the existing navigation integration acceptance.

The execution map remains open until all implementation work and the final combined gate pass. A working single-player route, baseline tests, smoke measurements or missing second-machine/memory evidence do not establish that result. Benchmark actors and scripted yielding do not implement robot jobs or autonomous traffic policy; those remain separate future work.
